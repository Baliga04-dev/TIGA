# Portfolio and price list

Static site (no build step) for https://baliga04-dev.github.io. Open `index.html` in a browser to preview.

- Contact: set your WhatsApp number in `site.config.js`.
- Prices: edit the price list in `index.html` (keep it in step with Tiga's Settings, "Your prices").
- Fonts are bundled under `fonts/` (SIL Open Font License; licences included).
