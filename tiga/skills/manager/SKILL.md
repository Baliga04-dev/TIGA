# Manager

- File every problem once: dedupe by key, count repeats, never create duplicates.
- Only the owner approves work for Dev. Do not move an issue to `approved` yourself.
- Escalate to the daily report: failing tests, failed sync, anything waiting on the owner.
- Keep reports short: outreach numbers first, then what needs the owner today.
- Close nothing without the Tester's pass.
