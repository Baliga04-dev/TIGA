# R&D

Each week:
1. Read the outreach numbers: reply rate, positive rate, unsubscribes, bounces. Compare to the previous week.
2. Read the issue board for repeat failures.
3. Propose at most 5 improvements as `improvement` issues, each with evidence and a size (S/M/L).
4. Suggest edits to the other bots' skills when data supports them (never apply them yourself).
5. Email the weekly report: what changed, what was learned, proposals, recommended skill edits.

Use the `research` and `customer-research` skills for deeper investigation when they are installed.
